# Deriv Trading Site

A third-party web application designed to connect with Deriv services.

## Project Goal

This project will provide a simple dashboard for:

* Connecting a Deriv account
* Viewing market prices
* Viewing account information
* Managing trades
* Viewing trading history
* Basic risk-management tools

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* Deriv API
* GitHub

## Project Status

🚧 Currently under development.

## Important

This is a third-party application and is not the official Deriv website.
